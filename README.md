# CareSync

**CareSync** is a mobile health management application developed using **Flutter and Dart**. The application is designed to help users organize and manage health-related information, medications, medical records, and health observations in one centralized platform.

## 📱 Features

* User registration and account validation
* Health record management
* Medication management
* Medication reminders
* Health observations tracking
* Patient information management
* Doctor and staff management
* Family medical history
* Organized health information
* Mobile-friendly user interface

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Figma** – UI/UX Design
* **Sql / Database** 

## 📌 Project Overview

CareSync is a mobile health management application created to provide users with an organized way to manage their health information.

The application allows users to access and manage medical records, medications, observations, and other health-related information through a centralized mobile interface.

The project focuses on creating a simple and accessible user experience while demonstrating mobile application development using Flutter.

Designed and developed the mobile application's user interface.

## 🎨 UI/UX Design

The application's interface and user experience were planned and designed with **Figma** before implementation.

The design focused on:

* Simple navigation
* Clear information hierarchy
* Easy access to health records
* User-friendly forms
* Mobile accessibility

## 🩺 Main Modules

### Health Records

Allows users to organize and access their health-related records.

### Medications

Provides medication management and reminder functionality.

### Observations

Allows users to record and monitor health observations.

### Doctor & Staff Management

Provides functionality for managing doctors and authorized staff within the system.

### User Registration

Includes validation and account registration functionality.

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/K-mariedizon/CareSync.git
   ```

2. Open the project in **Android Studio** or **Visual Studio Code** with Flutter installed.

3. Install the project dependencies:

   ```bash
   flutter pub get
   ```

4. Connect an Android device/emulator or configure another supported Flutter device.

5. Run the application:

   ```bash
   flutter run
   ```

## 🎯 Project Purpose

CareSync was developed as a mobile health management application to demonstrate skills in **Flutter development, Dart programming, UI/UX design, application logic, and health information management**.

The project combines mobile application development and user-centered interface design to create an organized and accessible health management experience.
